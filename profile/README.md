## 🧭 How We Work

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  1. Discover │───▶│  2. Design  │───▶│  3. Develop  │───▶│  4. Deliver  │
│              │    │             │    │              │    │              │
│ Requirements │    │ UX/UI       │    │ Full-stack   │    │ Launch, QA   │
│ Feasibility  │    │ Prototyping │    │ Engineering  │    │ 24/7 Support │
│ Scope        │    │ User Testing│    │ CI/CD        │    │ Iteration    │
│ (1-2 weeks)  │    │             │    │ Code Review  │    │              │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

- **Discover** — We start with your business problem, not a feature list. Requirements analysis, user research, technical feasibility, and scope definition. Usually 1–2 weeks.
- **Design** — User-centred design with wireframes, prototypes, and validated interfaces before a single line of code is written.
- **Develop** — Agile sprints with weekly demos. Full-stack engineering with code reviews, automated testing, and CI/CD from day one.
- **Deliver** — Rigorous QA, staged deployment, and 24/7 post-launch support. We stay on after launch because that's when the real work starts.
